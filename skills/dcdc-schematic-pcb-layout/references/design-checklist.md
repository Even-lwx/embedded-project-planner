# DCDC 设计检查清单与交付字段

## 原理图阶段字段

| 字段 | 必须内容 |
|---|---|
| 芯片证据 | 厂商、完整料号/后缀、数据手册版本、页码或章节、拓扑与限制 |
| 电气规格 | Vin min/nom/max、Vout、Iout 连续/峰值、纹波、效率目标、开关频率 |
| 功率器件 | 电感 L、Isat、Irms、RDC；二极管/开关的耐压、电流、损耗假设 |
| 电容 | 输入/输出/自举/补偿电容的有效容量、耐压、纹波、ESR、封装 |
| 控制网络 | FB 分压、补偿、软启动、限流、EN/PG、吸收/阻尼网络及计算过程 |
| 封装 | 推荐封装、焊盘/散热焊盘、替代封装的引脚兼容性 |
| 确认闸门 | 用户需要确认的数值、器件、方向、板框或资料缺口 |

## 布局阶段检查

- [ ] 输入陶瓷旁路紧贴电源开关回路，输入回路闭合且无不必要过孔。
- [ ] SW 节点面积受控，远离 FB、COMP、时钟、连接器和天线/敏感铜。
- [ ] 电感、输出电容和功率地形成最短输出回路；输出采样从安静点 Kelvin 引出。
- [ ] 栅极/自举路径短且有明确回流；同步整流的高低侧驱动回路无大环路。
- [ ] 反馈、补偿、EN/PG 使用干净的地参考，不跨越分割或高 di/dt 回路。
- [ ] 热焊盘、铜皮、过孔阵列和板层散热路径与封装建议一致。
- [ ] 线宽、过孔数量、载流能力、压降、温升、间距和可制造性已说明依据。
- [ ] 已标注探测点，便于测量 SW、栅极、输入纹波、输出纹波和环路响应。

## 可视化最小规范

图中至少包含：板框尺寸和方向箭头、输入/输出连接器、器件参考标号、SW 铜区、关键环路箭头、地平面/过孔符号、FB/COMP 走线、线宽或区域图例，以及“概念布局/待 PCB 工具复核”的状态标记。HTML 版本应能在无专用 EDA 软件时打开；SVG/PNG 应可直接嵌入对话。
